## 产品简介
Kindle WiFi 翻页器是一款基于 ESP32 的远程控制设备，通过 WiFi 网络与运行 KOReader 的 Kindle 设备通信，实现远程翻页、亮度调节和屏幕刷新等功能。

### 主要功能
+ **远程翻页**：下一页、上一页
+ **亮度调节**：调亮、调暗
+ **屏幕刷新**：全屏刷新
+ **设备发现**：自动扫描网络中的 Kindle 设备
+ **Web 配置**：通过网页进行配置和控制

### 支持的指令
| 指令 | 功能说明 |
| --- | --- |
| `nextpage` | 下一页 |
| `prevpage` | 上一页 |
| `brightness_up` | 调亮 |
| `brightness_down` | 调暗 |
| `refresh` | 刷新屏幕 |

## KOReader 插件安装
### 插件功能
KOReader 插件在 Kindle 上运行 UDP 服务器，监听端口 **8778**，接收来自 ESP32 翻页器的控制指令。

### 安装步骤
#### 1. 确认 KOReader 已安装
确保您的 Kindle 已经安装并运行 KOReader。

#### 2. 下载插件文件
从以下地址下载最新的插件包：

```plain
https://gitee.com/adamhxx/kindle-remote-control.koplugin/releases/tag/1.0.0
```

下载后解压，主要文件：

+ `main.lua` - 插件主程序

#### 3. 安装插件
**方法一：通过 KOReader 插件管理器（推荐）**

1. 将 `KindleRemoteControl.koplugin` 文件夹复制到 Kindle 的 KOReader 插件目录
2. Kindle 上的路径通常为：`/mnt/us/koreader/plugins/`
3. 重启 KOReader

**方法二：手动安装**

1. 使用 USB 连接 Kindle 到电脑
2. 进入 Kindle 的文件系统
3. 找到 KOReader 安装目录
4. 将 `KindleRemoteControl.koplugin` 文件夹复制到 `plugins` 目录
5. 安全弹出 Kindle
6. 重启 KOReader

#### 4. 启用插件
1. 打开 KOReader
2. 点击顶部菜单栏的 **设置** 图标
3. 找到 **Kindle Remote Control** 选项
4. 点击 **Start server** 启动服务器
5. 可选：启用 **Auto start server** 实现开机自启动

#### 5. 配置端口（可选）
默认端口为 **8778**，如需修改：

1. 在插件菜单中点击 **Port: 8778**
2. 输入新的端口号
3. 点击 OK 确认
4. 插件会自动重启服务器

## WiFi 配网配置
### 首次配网
设备首次上电或重置后，会创建一个名为 `XIAO_Kindle_Controller` 的 WiFi 热点。

#### 配网步骤
1. **连接热点**
    - 使用手机或电脑连接 `XIAO_Kindle_Controller` WiFi 网络
    - 密码：`koreaderhelper`
2. **访问配置页面**
    - 浏览器自动弹出配置页面
    - 如果没有弹出，访问 `192.168.4.1`
3. **配置 WiFi**
    - 在配置页面中选择您要连接的家庭/办公室 WiFi 网络
    - 输入 WiFi 密码
    - 点击保存
4. **等待连接**
    - 设备会尝试连接到配置的 WiFi 网络
    - 连接成功后，热点会自动关闭
5. **获取设备 IP**
    - 在路由器管理界面查看名为 `XIAO_Kindle_Controller` 的设备 IP
    - 或使用 mDNS 域名 `kop.local` 访问（如果路由器支持 mDNS）

### 重置 WiFi 配置
如需重新配网，可以重置设备：

**方法：长按刷新按键 5 秒以上**

+ 设备重启并进入配网模式
+ 重新连接 `XIAO_Kindle_Controller` 热点进行配置

## Web 配置界面使用
设备配网成功后，可以通过 Web 界面进行配置和控制。

### 访问 Web 界面
1. 确保电脑/手机与 ESP32 在同一局域网
2. 浏览器访问：
    - `http://kop.local`（如果支持 mDNS）
    - 或 `http://[ESP32的IP地址]`

### 界面功能说明
#### 1. ESP32 控制器配置
+ **设备 IP**：显示当前 ESP32 的 IP 地址
+ **状态**：显示连接状态（在线/离线）
+ **探测并保存**：手动输入 IP 并验证
+ **自动发现**：自动扫描局域网中的 ESP32 设备

#### 2. 目标设备 (Kindle) 配置
+ **当前 IP**：显示当前配置的 Kindle IP
+ **输入 Kindle IP**：手动输入 Kindle 的 IP 地址
+ **保存**：保存 Kindle IP 到 ESP32
+ **扫描**：扫描网络中运行 KOReader 插件的设备

#### 3. 操控面板
方向键式操控界面：

```plain
        ▲ 调亮
    ◄       ►
  上一页   下一页
        ▼ 调暗
    [刷新]
```

+ **上键**：增加亮度
+ **下键**：降低亮度
+ **左键**：上一页
+ **右键**：下一页
+ **中键**：刷新屏幕

#### 4. 设置
+ **清除缓存**：清除浏览器本地存储的配置信息

### 配置流程
1. **连接 ESP32**
    - 首次访问时，需要找到 ESP32 的 IP
    - 可以使用"自动发现"功能
    - 或手动输入 IP 后点击"探测并保存"
2. **配置 Kindle IP**
    - 在 Kindle 上查看 IP 地址（设置 → 网络）
    - 在 Web 界面输入 Kindle IP
    - 点击"保存"
3. **测试控制**
    - 使用操控面板测试各个功能
    - 确认 Kindle 能正确响应指令

## 按键功能说明
### 设备外观与按键布局
翻页器设备配备三个按键，布局如下：

```plain
┌─────────────┐
│   旋钮按键   │  ← 最上方（刷新/全刷）
├─────────────┤
│  机械按键1   │  ← 中间（下一页）
├─────────────┤
│  机械按键2   │  ← 最下方（上一页）
└─────────────┘
```

+ **旋钮按键**（最上方）：刷新/全刷功能
+ **机械按键1**（中间）：下一页功能
+ **机械按键2**（最下方）：上一页功能

### 物理按键定义
| 按键位置 | 按键类型 | 单击功能 | 长按功能 |
| --- | --- | --- | --- |
| 最上方 | 旋钮按键 | 刷新屏幕 | 重置 WiFi 配置（长按5秒） |
| 中间 | 机械按键 | 发送下一页指令 | 快速扫描并保存 Kindle 设备 IP（长按5秒） |
| 最下方 | 机械按键 | 发送上一页指令 | 无 |


### 按键操作示例
#### 阅读时翻页
1. 单击 **中间机械按键** → Kindle 翻到下一页
2. 单击 **最下方机械按键** → Kindle 翻到上一页

#### 刷新屏幕
当屏幕有残影时：

+ 单击 **最上方旋钮按键** → Kindle 执行全屏刷新

#### 快速扫描并配置 Kindle IP
当需要快速发现和配置 Kindle 设备时：

+ 长按 **中间机械按键** 5 秒以上
+ 设备会自动扫描网络中的 Kindle 设备
+ 扫描完成后自动保存第一个发现的设备 IP

#### 重置设备
当需要重新配置 WiFi 时：

+ 长按 **最上方旋钮按键** 5 秒以上
+ 设备重启并进入配网模式

## 常见问题解答
### Q1: 设备无法连接 WiFi
**可能原因：**

+ WiFi 密码错误
+ WiFi 信号太弱
+ 路由器设置了 MAC 地址过滤

**解决方法：**

1. 重置设备（长按刷新键5秒）
2. 重新连接热点进行配网
3. 确保输入正确的 WiFi 密码（`koreaderhelper`）

### Q2: 按键无响应
**可能原因：**

+ Kindle IP 未配置
+ KOReader 插件未运行
+ ESP32 与 Kindle 不在同一网络

**解决方法：**

1. 检查 Web 界面是否配置了 Kindle IP
2. 确认 KOReader 插件已启动（设置 → Kindle Remote Control → Start server）
3. 确认设备在同一局域网

### Q3: 无法访问 Web 配置页面
**可能原因：**

+ 设备 IP 未知
+ mDNS 不被支持

**解决方法：**

1. 在路由器管理界面查找设备 IP
2. 使用 IP 地址直接访问
3. 使用"自动发现"功能扫描设备

### Q4: 扫描不到 Kindle 设备
**可能原因：**

+ KOReader 插件未运行
+ 防火墙阻止了 UDP 通信
+ 网络隔离（如访客网络）

**解决方法：**

1. 确认 KOReader 插件已启动
2. 检查路由器设置，确保设备间可以通信
3. 手动输入 Kindle IP 地址

### Q5: 亮度调节无效
**可能原因：**

+ Kindle 不支持前光灯
+ 亮度已达到最大/最小值

**说明：**

+ 只有带前光灯的 Kindle 才支持亮度调节
+ 插件会显示当前亮度状态

### Q6: 如何查看 Kindle 的 IP 地址
**方法：**

1. 在 Kindle 主界面点击 **设置**
2. 进入 **网络** 或 **Wi-Fi** 设置
3. 查看当前连接的网络信息，IP 地址会显示在已连接的网络旁边

或者在 KOReader 中：

1. 点击顶部菜单的 **设置** 图标
2. 选择 **关于** 或 **设备信息**
3. 查看网络信息
